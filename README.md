# Сайт грузоперевозок «АВТОЛИНИЯ.BY»

Одностраничный лендинг для бизнеса грузоперевозок по Беларуси и России. База — Могилёв. Лёгкий, без зависимостей, готов к деплою на GitHub Pages.

---

## 📦 Что внутри

- `index.html` — весь сайт одним файлом (HTML + CSS + JS)
- `CNAME` — файл для привязки вашего `.by` домена
- `README.md` — эта инструкция

Включает: промо-баннер, мобильное меню, hero с формой быстрой заявки, блок преимуществ, секцию с цифрами и анимированными счётчиками, характеристики транспорта, калькулятор стоимости, типы грузов, процесс работы в 4 шага, отзывы клиентов, карту маршрутов из Могилёва, FAQ, плавающие кнопки мессенджеров.

## 📨 Подключение формы заявки

Заявки уходят в ваш Telegram-бот напрямую. Токен бота **уже встроен** в код — осталось добавить только `chat_id` (это ваш личный ID в Telegram, чтобы бот знал, кому слать).

### Как получить `chat_id` за 30 секунд:

1. Откройте Telegram → найдите своего бота → нажмите **«Запустить»** (`/start`)
2. Напишите ему любое сообщение, например `привет`
3. Откройте в браузере (только что, в новой вкладке):
   ```
   https://api.telegram.org/bot8792945237:AAEbjBqBClEc5IsKFVg6mT09LIZ3zF8_JSQ/getUpdates
   ```
4. Найдите в ответе блок `"chat":{"id":XXXXXXXXX,...}` — это число и есть ваш `chat_id`. Обычно 9–10 цифр, иногда со знаком минус (если групповой чат).
5. Откройте `index.html`, найдите строку:
   ```js
   const TG_CHAT_ID = 'YOUR_CHAT_ID';
   ```
   и замените `'YOUR_CHAT_ID'` на ваш номер в кавычках, например:
   ```js
   const TG_CHAT_ID = '123456789';
   ```
6. Сохраните, закоммитьте, запушьте — заявки начнут приходить в бот.

### Как выглядит заявка в Telegram:

```
🚛 НОВАЯ ЗАЯВКА С САЙТА

👤 Имя: Иван
📞 Телефон: +375 29 555-12-34
📍 Маршрут: Могилёв → Москва

⏰ 17.05.2026, 14:23 (МСК/Минск)
🌐 Источник: avtolinia.by · hero
```

### ⚠️ Безопасность

Токен бота встроен в HTML и виден всем, кто откроет исходный код сайта. Это нормально для статичных сайтов, но имейте в виду:
- В худшем случае посторонний сможет отправлять сообщения от имени вашего бота.
- Если такое произойдёт — откройте [@BotFather](https://t.me/BotFather) → `/revoke` → получите новый токен → обновите его в `index.html`.
- Для повышенной защиты можно поднять бэкенд-прокси (Vercel/Cloudflare Workers) — пишите, помогу.

## 🚀 Деплой на GitHub Pages

### 1. Создаём репозиторий
```bash
git init
git add .
git commit -m "Запуск сайта"
git branch -M main
git remote add origin https://github.com/ВАШ_АККАУНТ/avtolinia-by.git
git push -u origin main
```

### 2. Включаем GitHub Pages
- Откройте репозиторий на github.com
- Settings → Pages
- Source: `Deploy from a branch`
- Branch: `main` / `/ (root)` → **Save**

### 3. Привязываем `.by` домен
В файле `CNAME` пропишите ваш домен. Затем в DNS-настройках у регистратора:

**Для apex-домена (`вашдомен.by`):**
```
A  @  185.199.108.153
A  @  185.199.109.153
A  @  185.199.110.153
A  @  185.199.111.153
```

**Для поддомена `www`:**
```
CNAME  www  ВАШ_АККАУНТ.github.io.
```

### 4. Включаем HTTPS
Settings → Pages → дождитесь проверки домена (10–30 мин) → поставьте галочку **Enforce HTTPS**.
